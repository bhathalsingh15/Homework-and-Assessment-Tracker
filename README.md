# Homework & Assessment Tracker

Year 11 Applied Computing functional prototype.

## Files
- index.html
- style.css
- script.js

## Main features
- Dashboard
- Task add/edit-style management
- Search and filtering
- Calendar
- Progress tracking
- In-app reminders
- Profile/settings
- Dark mode
- Responsive mobile layout
- Browser local storage

## GitHub Pages
Create a GitHub repository, upload these three files to the repository root, then go to:
Settings -> Pages -> Deploy from a branch -> main -> /(root)

GitHub Pages looks for an entry file such as index.html.
